# SubscriptionCustomer

Customer `id` when not expanded, or the full `Customer` object when the field name is included in the `expand` query parameter. Can be null.


## Supported Types

### `string`

```php
/**
* @var string
*/
string $value = /* values here */
```

### `Components\Customer`

```php
/**
* @var \Juo\AdminAPI\Models\Components\Customer
*/
Components\Customer $value = /* values here */
```
